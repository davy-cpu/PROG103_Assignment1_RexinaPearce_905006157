 Small Business Sales Calculator 

A simple command-line sales calculator for small retail shops and market vendors in Sierra Leone. Built with Python using structured programming principles.
Features
- Add multiple items per sale with quantity and unit price
- Automatic subtotal calculation
- Apply percentage discounts and VAT/Tax
- Generate receipt with final total payable
- Save all transactions to `sales_log.csv`
- View daily sales summary: total sales, transactions, tax collected
- Runs offline - no internet or external libraries needed

 Tech Stack
- Language: Python 3.13
- Libraries: `csv`, `datetime`, `os` - all built-in
- Data Storage: CSV file
